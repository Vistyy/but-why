# Curate explicit reviewer Pi resources

Status: accepted

Acceptance Reviewers and Specialist Reviewers retain a fixed Pi resource boundary but explicitly load only the package-manager-policy and web-search extensions and the codebase-design skill.
Pi also loads the normal AGENTS.md and CLAUDE.md context files for the reviewer workspace.
The reviewer tool allowlist adds web_search, web_fetch, and web_content_get to read, bash, grep, find, and ls.
Prompt templates, themes, undiscovered extensions and skills, edit, write, and subagent tools remain unavailable.
This curated reviewer resource set is separate from configurable Agent Environment policy and remains a temporary reviewer capability decision.
