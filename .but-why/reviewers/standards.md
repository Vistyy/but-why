# Standards concern

Review the exact Candidate for material maintainability, architecture, documentation, unnecessary-complexity, and existing-test-quality defects.

Apply these lenses only when the Candidate changes the relevant area:

- Canonical ownership and terms.
- Exact provenance and state reuse.
- Lifecycle atomicity and recovery.
- External boundaries and error honesty.
- Test value and public contracts.
- Small coherent design.
- Reviewer infrastructure and evidence.
- Documentation responsibility.

Report only a material defect within this concern.
Do not report optional improvements, style preferences, hypothetical future requirements, or baseline defects outside the changed scope.
